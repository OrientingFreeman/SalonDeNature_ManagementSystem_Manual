    관리자 계정과 비밀번호¶

    18.1 관리자 계정¶

    이동 경로: 상단 메뉴 → 관리자 계정

    추가 관리자 계정이 필요할 때 사용합니다. 관리자 권한은 고객 개인정보와 매출에 접근할 수 있으므로 최소 인원에게만 부여하십시오.

    18.2 내 계정¶

    이동 경로: 상단 메뉴 → 내 계정

    현재 로그인한 관리자 비밀번호를 변경합니다.

    권장 사항:

    • 다른 서비스와 같은 비밀번호를 사용하지 않기
    • 추측하기 어려운 비밀번호 사용
    • 직원 계정과 관리자 계정을 구분하기
    • 퇴사자 또는 권한이 필요 없는 사람의 계정 즉시 비활성화
