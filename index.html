    Salon De Nature 운영 매뉴얼¶

    원장님과 관리자를 위한 시스템 사용 설명서¶

    예약 접수부터 예약금 확인, 고객 CRM, 직원 일정, 매출 분석, 문자 발송까지 실제 운영 순서에 맞춰 설명합니다.

    오늘 운영 시작하기 예약 관리 보기

    빠른 메뉴¶

    • 관리자 대시보드

      오늘 예약, 대기 예약과 매출을 확인합니다.

      대시보드 열기

    • 예약 관리

      예약 등록, 변경, 확정, 취소, 완료와 노쇼를 처리합니다.

      예약 캘린더

    • 고객 CRM

      고객 검색, 메모, 세그먼트와 예약 이력을 관리합니다.

      고객 관리

    • 직원 관리

      직원 계정, 근무 일정과 담당 서비스를 설정합니다.

      직원 관리

    • 매출 분석

      기간별 매출과 직원·서비스별 실적을 확인합니다.

      매출 분석

    • 알림과 문자

      알림센터, SMS 테스트와 문자 템플릿을 관리합니다.

      문자 관리

    가장 자주 쓰는 업무¶

    업무 이동 경로
    오늘 예약 확인 관리자 로그인 → 대시보드
    전화·카카오톡 예약 등록 고객 관리에서 고객 확인 → 캘린더 → 예약 등록
    예약금 입금 확인 캘린더 또는 타임라인 → 해당 예약
    시술 완료 처리 예약 상세 또는 직원 화면 → 완료
    고객 메모 확인 고객 관리 → 고객 상세
    직원 휴무 설정 직원 관리 → 일정 관리
    당일 매출 확인 매출 분석
    문자 발송 실패 확인 알림센터 또는 예약 처리 이력

    개인정보 보호

    이 문서 사이트에 포함된 실제 고객 정보가 있는 스크린샷은 공개 저장소에 올리기 전에 반드시 가림 처리하십시오. 현재 제공된 화면도 저장소 공개 여부를 결정하기 전에 한 번 더 확인하는 것이 안전합니다.
