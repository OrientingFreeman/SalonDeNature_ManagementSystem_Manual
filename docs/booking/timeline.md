# 타임라인 대시보드

**이동 경로:** 관리자 대시보드 또는 캘린더에서 타임라인 진입  
또는 관련 예약 상세 → `타임라인`

타임라인은 하루 예약을 담당 직원별 시간표 형태로 보는 운영 화면입니다.

## 8.1 주요 기능

- 이전 날짜 / 오늘 / 다음 날짜 이동
- 특정 날짜 검색
- 직원별 예약 시간대 확인
- 예약 블록을 선택해 상세 팝업 열기
- 예약 시간 변경
- 직원·서비스 재배정
- 예약금 입금 완료 처리
- 상태를 확인·완료·노쇼·취소로 변경
- 전체 상세 페이지 이동
- 캘린더 이동

## 8.2 예약 블록 이동

드래그 기능이 활성화된 경우 예약 블록을 다른 시간대로 이동할 수 있습니다.

처리 전 확인할 사항:

1. 고객에게 변경 시간을 확인했는지
2. 직원의 근무시간인지
3. 다른 예약과 겹치지 않는지
4. 시술 소요시간이 확보되는지

## 8.3 팝업 상세

예약 블록을 열면 상태, 예약금, 고객 정보와 처리 버튼을 볼 수 있습니다. 모바일에서는 팝업 내부를 위아래로 스크롤해야 하단 버튼이 보일 수 있습니다.

!!! danger "주의"
    타임라인의 드래그 이동은 실제 예약 시간을 변경합니다. 단순히 화면 배치만 바뀌는 것이 아닙니다.
