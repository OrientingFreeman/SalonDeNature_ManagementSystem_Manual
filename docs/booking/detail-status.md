# 예약 상세와 상태 처리

**이동 경로 1:** 캘린더 → 예약 선택 → `전체 상세`  
**이동 경로 2:** 타임라인 → 예약 선택 → `전체 상세`  
**이동 경로 3:** 고객 상세 → 예약 이력 → `Details`

예약 상세 화면은 개별 예약을 정확하게 처리하는 핵심 화면입니다.

## 7.1 예약 정보

다음 정보가 한 화면에 표시됩니다.

- 고객명, 전화번호, 이메일
- 서비스와 가격
- 담당 직원
- 예약 일시
- 예약금 상태
- 예약 생성 시각
- 예약 메모
- 예약금 메모

## 7.2 상태 처리 버튼

예약의 현재 상태에 따라 가능한 버튼만 표시됩니다.

### Pending 상태

- **예약 확정**
- **예약 취소**

### Confirmed 상태

- **시술 완료**
- **노쇼 처리**
- **예약 취소**

### Completed, Cancelled, No-show 상태

최종 상태이므로 추가 상태 변경 버튼이 표시되지 않습니다.

## 7.3 처리 사유와 메모

- 예약 확정과 완료는 메모가 선택 사항입니다.
- 취소와 노쇼는 사유가 필수입니다.
- 입력한 사유는 예약 처리 이력에 저장됩니다.

## 7.4 예약 처리 이력

예약 생성부터 현재까지 다음 기록을 시간순으로 확인할 수 있습니다.

- 예약 생성
- 일정 변경
- 담당자 변경
- 예약금 처리
- 상태 변경
- 고객·관리자 문자 발송 결과
- 실패 또는 건너뜀 사유
