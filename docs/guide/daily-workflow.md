# 하루 운영 절차

## 21.1 영업 시작 전

1. 관리자 로그인
2. 대시보드에서 오늘 예약 확인
3. Pending 예약 확인
4. 계좌 입금 내역 확인
5. 입금된 예약을 Confirmed 처리
6. 캘린더에서 직원별 시간과 서비스 확인
7. 휴무 또는 일정 변경 여부 확인
8. 알림센터에서 미확인 변경·취소 확인

## 21.2 예약 접수 시

### 고객이 홈페이지에서 직접 예약한 경우

1. 신규 예약 알림 확인
2. 고객·서비스·직원·일시 확인
3. 예약금 요청 또는 입금 확인
4. Confirmed 처리
5. 문자 발송 이력 확인

### 전화 또는 카카오톡으로 예약한 경우

1. 고객 관리에서 전화번호 검색
2. 고객이 없으면 신규 고객 등록
3. 캘린더에서 관리자 예약 생성
4. 서비스·직원·시간 선택
5. 예약금 안내
6. 입금 후 확정

## 21.3 시술 직전

1. 고객 상세의 민감도·주의사항 확인
2. 예약 메모 확인
3. 담당 직원과 서비스 확인
4. 예약금 상태 확인

## 21.4 시술 후

1. 직원 또는 관리자가 Completed 처리
2. 매출 반영 확인
3. 필요한 경우 고객 메모 갱신
4. 다음 예약 또는 권장 방문 시기를 별도 안내

## 21.5 영업 종료 전

1. Confirmed 상태로 남은 지난 예약 확인
2. 실제 방문 고객은 Completed 처리
3. 미방문 고객은 사유를 입력해 No-show 처리
4. 취소 예약 상태 확인
5. 당일 매출 확인
6. 알림센터 정리
