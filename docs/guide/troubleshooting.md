# 문제 해결

## 23.1 고객 예약 화면에 시간이 나오지 않음

다음 순서로 확인합니다.

1. 서비스가 활성 상태인지
2. 직원이 활성 상태인지
3. 직원에게 해당 서비스가 연결되었는지
4. 직원의 해당 요일 근무시간이 등록되었는지
5. 휴무·반차가 등록되어 있는지
6. 기존 예약과 겹치는지
7. 서비스 소요시간이 영업시간 안에 들어오는지

## 23.2 고객에게 문자가 가지 않음

1. SOLAPI 발신번호 승인 상태
2. API Key와 Secret 설정
3. SOLAPI 잔액
4. SMS 발송 활성화 여부
5. 고객 전화번호
6. 해당 문자 템플릿 활성화 여부
7. 알림센터 또는 예약 처리 이력의 발송 결과
8. 실패 메시지 확인

## 23.3 예약이 매출에 포함되지 않음

예약 상태가 Completed인지 확인하십시오. Confirmed는 예약 확정 상태이지 매출 완료 상태가 아닙니다.

## 23.4 직원이 자신의 예약을 볼 수 없음

1. 올바른 직원 계정으로 로그인했는지
2. 예약의 담당 직원이 해당 직원인지
3. 예약 날짜 필터가 맞는지
4. 직원 계정이 활성 상태인지

## 23.5 고객이 중복 등록됨

고객을 새로 추가하기 전 이름보다 전화번호를 우선 검색하십시오. 중복 고객의 자동 병합 기능은 별도 확인이 필요하므로 임의 삭제 전에 예약 이력을 확인하십시오.

## 23.6 관리자 화면에서 영어 상태명이 보임

일부 내부 상태 값은 시스템 표준 값으로 표시될 수 있습니다.

| 내부 상태 | 의미 |
|---|---|
| pending | 예약 대기 |
| confirmed | 예약 확정 |
| completed | 시술 완료 |
| cancelled | 예약 취소 |
| no_show | 노쇼 |
