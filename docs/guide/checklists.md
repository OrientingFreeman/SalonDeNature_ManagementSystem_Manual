# 부록: 빠른 이동표

| 하고 싶은 작업 | 이동 경로 |
|---|---|
| 오늘 예약 보기 | 관리자 로그인 → 대시보드 |
| 날짜별 예약 보기 | 상단 메뉴 → 캘린더 |
| 전화 예약 등록 | 고객 관리에서 고객 확인 → 캘린더 → 예약 등록 |
| 예약 확정 | 캘린더/타임라인 → 예약 → 예약 확정 |
| 시술 완료 | 캘린더/타임라인/직원 화면 → 예약 완료 |
| 노쇼 처리 | 예약 상세 → 노쇼 처리 → 사유 입력 |
| 고객 메모 수정 | 고객 관리 → 고객 상세 |
| 고객 현황 엑셀 | 고객 관리 → 엑셀 다운로드 |
| 서비스 추가 | 서비스 관리 → 새 서비스 추가 |
| 직원 추가 | 직원 관리 → 새 디자이너 추가 |
| 직원 근무시간 | 직원 관리 → 직원 → 일정 관리 |
| 직원 담당 서비스 | 직원 관리 → 직원 → 서비스 관리 |
| 매출 확인 | 매출 분석 |
| 문자 발송 실패 확인 | 알림센터 또는 예약 상세 처리 이력 |
| 문자 문구 수정 | 알림센터 → 문자 템플릿 |
| 예약금·계좌 설정 | 설정 |
| 관리자 비밀번호 변경 | 내 계정 |
| 전체 알림 확인 | 종 아이콘 → 전체 알림 보기 |
