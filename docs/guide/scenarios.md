# 상황별 처리 방법

## 22.1 예약금이 입금된 경우

**경로:** 캘린더 또는 타임라인 → 해당 예약

1. 고객명과 예약 날짜 확인
2. 실제 계좌 입금자·금액 확인
3. 예약금 입금 완료 처리
4. Pending이면 Confirmed 처리
5. 고객·관리자 문자 발송 이력 확인

## 22.2 고객이 예약을 변경한 경우

**경로:** 캘린더 또는 타임라인 → 예약 변경

1. 고객과 새 날짜·시간 합의
2. 예약 가능 시간 조회
3. 새 시간 선택
4. 저장
5. 담당 직원에게 변경 내용 전달
6. 문자 발송 확인

## 22.3 고객이 취소한 경우

**경로:** 예약 상세 → 예약 취소

1. 고객명과 예약 확인
2. 취소 사유 입력
3. 취소 확정
4. 예약금 환불 정책에 따라 별도 정산
5. 취소 문자 확인

현재 시스템의 매출 분석은 서비스 가격과 예약 상태를 중심으로 하며, 실제 환불·할인 회계는 별도 확인이 필요할 수 있습니다.

## 22.4 고객이 방문하지 않은 경우

**경로:** 예약 상세 또는 타임라인 → 노쇼 처리

1. 연락 여부 확인
2. 노쇼 사유 입력
3. No-show 처리
4. 고객 CRM의 위험도와 예약 제한 여부 확인
5. 필요하면 고객 메모 기록

## 22.5 직원이 갑자기 쉬는 경우

1. 캘린더에서 해당 직원의 기존 예약 확인
2. 다른 직원이 서비스를 담당할 수 있는지 확인
3. 고객에게 변경 가능 여부 연락
4. 예약 배정 변경
5. 직원 관리 → 일정 관리에서 휴무 등록
6. 새 예약이 들어오지 않는지 확인

## 22.6 신규 서비스를 출시하는 경우

1. 서비스 관리에서 서비스 추가
2. 가격·소요시간·예약금 입력
3. 직원 관리 → 담당 서비스에서 가능한 직원 선택
4. 직원 근무 일정 확인
5. 고객 예약 화면에서 서비스와 시간이 표시되는지 테스트

## 22.7 신규 직원을 등록하는 경우

1. 직원 관리에서 계정과 프로필 생성
2. 근무 일정 설정
3. 담당 서비스 설정
4. 활성 상태 확인
5. 직원 로그인 테스트
6. 고객 예약 화면에서 정상 노출 확인
